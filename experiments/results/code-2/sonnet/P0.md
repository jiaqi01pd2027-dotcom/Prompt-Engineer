```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```

Output now:
```
[{'id': 1, 'tags': ['processed']}]
[{'id': 2, 'tags': ['processed']}]
[1.5, 2.5, 3.5]
['1: alpha', '2: beta']
```

**What was wrong:**

1. **`tag_records`** — mutable default argument (`tags=[]`). Python creates that default list *once*, at function-definition time, and reuses it on every call that doesn't pass `tags` explicitly. So each call kept appending `"processed"` to the same shared list — the second call in `__main__` would have printed `tags: ['processed', 'processed']`. Fixed by defaulting to `None` and creating a fresh list inside the function.

2. **`moving_average`** — off-by-one in the loop bound. `range(len(values) - window)` stops one slice too early, silently dropping the last valid window. For `[1,2,3,4]` with `window=2`, the buggy version only returned `[1.5, 2.5]` (windows `[1,2]` and `[2,3]`), missing `[3,4]` → `3.5`. Fixed with `range(len(values) - window + 1)`.

`number_lines` had no bug — it was already correct as written.
