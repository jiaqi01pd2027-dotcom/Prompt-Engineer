## Bug 1 — `tag_records`: mutable default argument

**Why it's wrong:** `tags=[]` creates the list **once**, at function-definition time, and it is reused across every call that doesn't pass its own `tags`. Since the body does `tags.append("processed")` — mutating that shared list in place — each subsequent call keeps appending to the *same* list object. Running the `__main__` block proves it:

```
tag_records([{"id": 1}])  -> tags become ['processed']
tag_records([{"id": 2}])  -> tags become ['processed', 'processed']   # bug!
```

The second call was supposed to start fresh but instead inherited state from the first call.

**Fix:** use `None` as the sentinel default and create a new list inside the function body.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

## Bug 2 — `moving_average`: off-by-one in the loop range, drops the last window

**Why it's wrong:** `range(len(values) - window)` produces one fewer starting index than it should. For a list of length `n` and window size `w`, there are `n - w + 1` valid starting positions (the last valid start is `n - w`, which `range(n - w)` never yields). With `values=[1, 2, 3, 4]` and `window=2`, this currently computes `[1.5, 2.5]` and silently drops the final chunk `[3, 4]` (average `3.5`).

**Fix:** add the missing `+ 1`.

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```

Correct output for the example is now `[1.5, 2.5, 3.5]`.
