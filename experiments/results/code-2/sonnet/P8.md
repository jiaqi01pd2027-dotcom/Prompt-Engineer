Bug 1
Function: tag_records
Problem: The default argument `tags=[]` is a single list object shared across all calls, and `tags.append("processed")` mutates it in place, so each subsequent call in a batch keeps appending another "processed" onto the same growing list.
Fix: Default `tags` to `None` and build a fresh local list from it inside the function instead of mutating a shared/passed-in list.

Bug 2
Function: moving_average
Problem: `range(len(values) - window)` produces one too few start positions (e.g. for 4 values and window 2 it yields only `0, 1` instead of `0, 1, 2`), dropping the last valid slice.
Fix: Use `range(len(values) - window + 1)` so every valid window start position, including the last one, is included.

Corrected code
```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    if tags is None:
        tags = []
    tags = list(tags) + ["processed"]
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
