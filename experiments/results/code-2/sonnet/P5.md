## Bug 1

Function: tag_records
Problem: The default argument `tags=[]` is created once when the function is defined, and `tags.append("processed")` mutates that same shared list on every call, so subsequent calls (without an explicit `tags` argument) accumulate extra "processed" markers from previous calls.
Fix: Use `tags=None` as the default and create a fresh list (`tags = [] if tags is None else list(tags)`) inside the function body.

## Bug 2

Function: moving_average
Problem: `range(len(values) - window)` stops one iteration too early, so the last valid window (starting at index `len(values) - window`) is never included — e.g. with `[1, 2, 3, 4]` and `window=2` it omits the `[3, 4]` slice.
Fix: Use `range(len(values) - window + 1)` so the final window is included.

## Corrected code

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = [] if tags is None else list(tags)
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
