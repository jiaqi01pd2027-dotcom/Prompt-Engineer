## Bugs found

**Bug 1 — `tag_records`: mutable default argument**

The parameter `tags=[]` is a classic Python trap: the default list object is created **once**, at function-definition time, and reused across every call that doesn't pass its own `tags`. `tags.append("processed")` mutates that same shared list each time, so it grows on every subsequent call.

Proof from the `__main__` block: the two `tag_records([...])` calls each rely on the default, so the second call's records get `["processed", "processed"]` instead of `["processed"]`, and a third call would get three, etc.

Fix — don't use a mutable default; build a fresh list per call:

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

**Bug 2 — `moving_average`: off-by-one range, drops the last window**

`range(len(values) - window)` produces one too few start positions, so the final valid window is silently skipped.

Proof: `values=[1,2,3,4]`, `window=2` → `len(values)-window = 2` → `range(2)` gives `start = 0, 1`, producing windows `[1,2]` and `[2,3]` only. The valid final window `[3,4]` (average 3.5) is never computed — the function returns `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

Fix — the loop needs to include the last starting index, i.e. `len(values) - window + 1` iterations:

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```
