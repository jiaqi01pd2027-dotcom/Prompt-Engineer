Confirmed both bugs empirically: `tag_records` accumulates "processed" across calls (second call returns `['processed', 'processed']`), and `moving_average` drops the last window (`[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`).

**Bug 1 — `tag_records`:** uses a mutable default argument `tags=[]`. Because the same list object is reused across calls and mutated in place with `tags.append(...)`, calling the function again without an explicit `tags` argument keeps growing that shared list, so unrelated calls leak state into each other.

**Bug 2 — `moving_average`:** the loop range is `range(len(values) - window)`, which is off by one and drops the final valid window. It should be `range(len(values) - window + 1)` so the last slice (e.g., `[3, 4]` when `values=[1,2,3,4], window=2`) is included.

`number_lines` was left unchanged — it's correct.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    if tags is None:
        tags = []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
