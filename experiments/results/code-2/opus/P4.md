Two bugs, both confirmed by running the snippet.

**Bug 1 — `tag_records`: mutable default argument.** The default `tags=[]` is created once at function-definition time and reused by every call that omits the argument, so `tags.append("processed")` accumulates across calls. The original prints `['processed']` then `['processed', 'processed']` for the second record. Using `None` as the sentinel and copying the caller's list fixes it without mutating a caller-supplied list.

**Bug 2 — `moving_average`: off-by-one in the loop bound.** A list of length `n` has `n - window + 1` consecutive windows, but `range(len(values) - window)` produces one fewer, dropping the final window. For `[1, 2, 3, 4]` with `window=2` it returned `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

`number_lines` is correct as written (`enumerate(..., start=1)` already yields 1-based numbering) and is unchanged.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```

Corrected output: `[{'id': 1, 'tags': ['processed']}]`, `[{'id': 2, 'tags': ['processed']}]`, `[1.5, 2.5, 3.5]`, `['1: alpha', '2: beta']`.
