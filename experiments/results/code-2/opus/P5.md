Bug 1
Function: tag_records
Problem: The default argument `tags=[]` is a mutable default evaluated once at definition time, so the same list is reused across calls and `tags.append("processed")` accumulates markers (second call yields `['processed', 'processed']`); it also mutates a caller-supplied list as a side effect.
Fix: Default `tags` to `None` and build a fresh local copy inside the function before appending.

Bug 2
Function: moving_average
Problem: `range(len(values) - window)` stops one iteration early, so the final full window is never averaged — `moving_average([1,2,3,4], 2)` returns `[1.5, 2.5]` instead of the three expected slices.
Fix: Iterate over `range(len(values) - window + 1)`.

Corrected code

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```

Verified by running the corrected snippet: output is `[{'id': 1, 'tags': ['processed']}]`, `[{'id': 2, 'tags': ['processed']}]`, `[1.5, 2.5, 3.5]`, `['1: alpha', '2: beta']`. `number_lines` was already correct and is unchanged.
