Two real bugs; the third function was already correct.

**Bug 1 — `tag_records`: mutable default argument.** `tags=[]` is created once at function-definition time, so `"processed"` accumulates across calls. The original output proves it: the second call returned `tags: ['processed', 'processed']`. It also mutates any list the caller passes in.

**Bug 2 — `moving_average`: off-by-one, drops the last window.** `range(len(values) - window)` yields one window too few. `moving_average([1, 2, 3, 4], 2)` returned `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`. With `window == len(values)` it returned `[]`. The count of windows is `len(values) - window + 1`.

**`number_lines` is fine.** `enumerate(lines, start=1)` already produces `['1: alpha', '2: beta']` — matches the docstring, no change needed.

Fixed code:

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    all_tags = list(tags) if tags is not None else []
    all_tags.append("processed")
    return [dict(record, tags=list(all_tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    if window <= 0:
        raise ValueError("window must be positive")
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]
```

The `None` sentinel plus the defensive `list(tags)` copy fixes both halves of bug 1 — no shared state between calls, and the caller's list is left untouched. I added a guard on non-positive `window`, since `window=0` would otherwise divide by zero.

Verified output after the fix: repeated `tag_records` calls each give `['processed']`, passing `["urgent"]` gives `['urgent', 'processed']`, `moving_average([1,2,3,4], 2)` gives `[1.5, 2.5, 3.5]`, and `moving_average([1,2,3,4], 4)` gives `[2.5]`.
