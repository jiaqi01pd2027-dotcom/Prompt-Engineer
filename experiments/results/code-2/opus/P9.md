Two bugs found and fixed; verified by running the corrected snippet.

**Bug 1 — `tag_records`: mutable default argument.** `tags=[]` is created once at function-definition time and shared across every call. `tags.append("processed")` mutates that shared list, so the second call sees `["processed", "processed"]`, the third sees three, and so on — exactly the accumulation you're seeing in batches. Fixed with the `None` sentinel, plus a copy of any caller-supplied list so a caller's list is never mutated either.

**Bug 2 — `moving_average`: off-by-one in the loop bound.** For `n` values and window `w` there are `n - w + 1` slices, but `range(len(values) - window)` produces only `n - w`, dropping the final window. `moving_average([1, 2, 3, 4], 2)` returned `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

`number_lines` is correct — `enumerate(lines, start=1)` already gives the 1-based numbering the diff viewer wants. Left untouched.

Verified output:
```
[{'id': 1, 'tags': ['processed']}]
[{'id': 2, 'tags': ['processed']}]
[1.5, 2.5, 3.5]
['1: alpha', '2: beta']
```

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
