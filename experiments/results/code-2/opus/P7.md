Reasoning per function:

**`tag_records`** — Docstring promises `tags` plus one `'processed'` marker per record. First call gives `['processed']`, second gives `['processed', 'processed']`. The default `[]` is created once at function-definition time and shared across calls; `tags.append` mutates that shared object, so the marker accumulates. Confirmed bug.

**`moving_average`** — For `[1, 2, 3, 4]` with `window=2` the consecutive 2-slices are `[1,2]`, `[2,3]`, `[3,4]` → expected `[1.5, 2.5, 3.5]`. Got `[1.5, 2.5]`. `range(len(values) - window)` yields `0, 1` but there are `len(values) - window + 1 = 3` valid start positions; the last window is dropped. Confirmed bug.

**`number_lines`** — `enumerate(lines, start=1)` gives `1: alpha`, `2: beta`, exactly matching the docstring's example. Looks suspicious at a glance (off-by-one indexing is a common bug here) but the `start=1` is already correct. Not a bug — left alone.

## Findings:

**Bug 1 — `tag_records`: mutable default argument**

`tags=[]` is evaluated once when the function is defined, so every call that omits `tags` shares and mutates the same list. Markers pile up across calls, and a caller who *does* pass a list gets it mutated as a side effect.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

**Bug 2 — `moving_average`: off-by-one in the loop bound**

A sequence of length `n` has `n - window + 1` windows of size `window`, but the loop ranges over `n - window`, so the final window is never produced.

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```

With both fixes, the `__main__` block prints `[{'id': 1, 'tags': ['processed']}]`, `[{'id': 2, 'tags': ['processed']}]`, `[1.5, 2.5, 3.5]`, and `['1: alpha', '2: beta']`.
