Verified: original prints duplicate tags on the second call and `[1.5, 2.5]` for the moving average; the corrected version prints one `processed` per call and three averages.

## Bug 1

Function: `tag_records`
Problem: The default `tags=[]` is a single list object created once at definition time, so `tags.append("processed")` mutates it permanently and every later call accumulates another `"processed"` entry.
Fix: Default to `None` and bind a fresh local copy (`tags = [] if tags is None else list(tags)`) before appending, which also stops a caller-supplied list from being mutated.

## Bug 2

Function: `moving_average`
Problem: `range(len(values) - window)` yields one start index too few, dropping the final full window — a 4-item list with window 2 has 3 valid slices but only starts 0 and 1 are visited.
Fix: Iterate `range(len(values) - window + 1)`.

## Corrected code

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = [] if tags is None else list(tags)
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
