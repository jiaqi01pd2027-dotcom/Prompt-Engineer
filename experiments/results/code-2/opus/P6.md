**Function: `tag_records`**

Problem: `tags=[]` is a mutable default, and `tags.append("processed")` mutates it in place. The same list object is reused on every call that omits `tags`, so the marker accumulates. The `__main__` block shows it: the first call yields `tags: ['processed']`, the second yields `tags: ['processed', 'processed']`, and it keeps growing. The same `append` also mutates a caller-supplied list as a side effect.

Fix: default to `None` and build a fresh local list inside the function (copying the caller's list rather than mutating it).

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

**Function: `moving_average`**

Problem: `range(len(values) - window)` is off by one and drops the final window. With `n` values there are `n - window + 1` consecutive slices of size `window`, so the last valid start index is `n - window`, which `range(n - window)` never reaches. `moving_average([1, 2, 3, 4], 2)` returns `[1.5, 2.5]` and silently loses `3.5`. The degenerate case is worse: `window == len(values)` returns `[]` instead of the one average covering the whole list.

Fix: use `range(len(values) - window + 1)`.

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```

After the fix: `moving_average([1, 2, 3, 4], 2)` → `[1.5, 2.5, 3.5]`, `moving_average([1, 2, 3, 4], 4)` → `[2.5]`, and `moving_average([1, 2], 3)` → `[]` (a negative range is still empty, so the too-short case stays correct).
