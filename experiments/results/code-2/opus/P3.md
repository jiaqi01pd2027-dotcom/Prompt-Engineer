## Bug 1 — `tag_records`: mutable default argument

`tags=[]` is evaluated **once**, at function-definition time, so every call that omits `tags` shares the same list object. `tags.append("processed")` mutates that shared list, so it grows on each call: the first record gets `['processed']`, the second `['processed', 'processed']`, and so on — exactly the duplicate "processed" tags reported later in a batch. (Original output: `[{'id': 2, 'tags': ['processed', 'processed']}]`.)

Fix — use `None` as the sentinel, and copy the caller's list so an explicitly passed list is never mutated either:

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

## Bug 2 — `moving_average`: off-by-one in the range

For a list of length `n` and window `w`, the valid start indices are `0 .. n - w`, which is `n - w + 1` windows. `range(len(values) - window)` stops one short, dropping the final full window. With `[1, 2, 3, 4]` and `window=2` it yielded `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

Fix:

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```
