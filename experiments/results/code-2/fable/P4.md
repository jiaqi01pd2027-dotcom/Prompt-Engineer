**Bug 1 — `tag_records`:** the default `tags=[]` is a mutable default argument, created once at definition time and shared across calls. Each call appends `"processed"` to that same list, so the second call in `__main__` prints `tags=['processed', 'processed']` instead of `['processed']`. Fix: default to `None` and create a fresh list per call.

**Bug 2 — `moving_average`:** `range(len(values) - window)` stops one slice short, because the last valid window starts at index `len(values) - window`. For `[1, 2, 3, 4]` with `window=2` it returns `[1.5, 2.5]` and drops the final `3.5`. Fix: use `range(len(values) - window + 1)`.

`number_lines` is correct as written (`enumerate(..., start=1)` already produces `'1: alpha'`).

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    if tags is None:
        tags = []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```

Expected output after the fix:

```
[{'id': 1, 'tags': ['processed']}]
[{'id': 2, 'tags': ['processed']}]
[1.5, 2.5, 3.5]
['1: alpha', '2: beta']
```
