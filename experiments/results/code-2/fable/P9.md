Both bugs are confirmed by your answers; `number_lines` is correct as written and I've left it untouched.

**Bug 1 — `tag_records`: mutable default argument.** `tags=[]` is evaluated once at function definition, so the same list object is shared across every call that omits `tags`. Each call appends another `"processed"` to it, which is exactly the accumulation you're seeing. Fix: default to `None`, build a fresh list inside the function, and don't mutate the caller's list either.

**Bug 2 — `moving_average`: off-by-one in the loop range.** `range(len(values) - window)` yields one too few start positions, so the last window is never averaged. With 4 values and window 2, valid starts are 0, 1, 2 — three of them. The range needs `+ 1`.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```

Expected output now:

```
[{'id': 1, 'tags': ['processed']}]
[{'id': 2, 'tags': ['processed']}]
[1.5, 2.5, 3.5]
['1: alpha', '2: beta']
```
