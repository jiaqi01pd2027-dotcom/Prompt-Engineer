Bug 1
Function: tag_records
Problem: The mutable default `tags=[]` is created once at definition time, and `tags.append("processed")` mutates it, so every call without an explicit `tags` argument accumulates another "processed" entry (the second call in `__main__` yields `['processed', 'processed']`). Callers that pass their own list also get it mutated as a side effect.
Fix: Default to `None`, and build a fresh list that includes "processed" instead of appending to the caller's list.

Bug 2
Function: moving_average
Problem: `range(len(values) - window)` stops one slice short, so the final full window is never averaged (`moving_average([1, 2, 3, 4], 2)` returns `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`).
Fix: Iterate over `range(len(values) - window + 1)` so the last full window is included.

Corrected code
```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
