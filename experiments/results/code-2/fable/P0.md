Two of the three functions had bugs; `number_lines` was already correct (`enumerate(lines, start=1)` gives 1-based numbering as documented).

**Bug 1: `tag_records` — mutable default argument.** `tags=[]` is created once at function definition, so `tags.append("processed")` mutates the shared list on every call. The second call would produce `['processed', 'processed']`, and any list a caller passed in would be mutated too. Fix: default to `None` and copy the caller's list.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

**Bug 2: `moving_average` — off-by-one.** `range(len(values) - window)` drops the last window. For `[1, 2, 3, 4]` with window 2 it returned `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

```python

```

Full corrected file:

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]


def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages


def number_lines(lines):
    """Prefix each line with its 1-based line number, e.g. '1: first'."""
    return [f"{index}: {line}" for index, line in enumerate(lines, start=1)]


if __name__ == "__main__":
    print(tag_records([{"id": 1}]))
    print(tag_records([{"id": 2}]))
    print(moving_average([1, 2, 3, 4], 2))
    print(number_lines(["alpha", "beta"]))
```
