**Bug 1 — `tag_records`: mutable default argument**

`tags=[]` is evaluated once, when the function is defined, so every call that omits `tags` shares the same list. `tags.append("processed")` mutates that shared list, so the marker accumulates across calls: the first call yields `['processed']`, the second `['processed', 'processed']`, and so on. (Callers who do pass a list also get it mutated as a side effect.)

Fix: use `None` as the default and build a fresh list inside the function, without mutating the caller's list.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

Now `tag_records([{"id": 1}])` and `tag_records([{"id": 2}])` both return `tags=['processed']`.

**Bug 2 — `moving_average`: off-by-one in the loop bound**

The number of consecutive `window`-sized slices in a list of length `n` is `n - window + 1`, but `range(len(values) - window)` produces only `n - window` start indices, so the final slice is always dropped. For `[1, 2, 3, 4]` with `window=2` it returns `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.

Fix:

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```
