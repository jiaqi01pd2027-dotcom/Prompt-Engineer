**Tracing the `__main__` block**

1. `tag_records([{"id": 1}])` — `tags` defaults to a list object created once at function definition. First call appends `"processed"` and returns `[{'id': 1, 'tags': ['processed']}]`. Correct so far.
2. `tag_records([{"id": 2}])` — same default list object, now already containing `"processed"`. It appends again and returns `[{'id': 2, 'tags': ['processed', 'processed']}]`. The docstring promises "`tags` plus a 'processed' marker", i.e. one marker; the second call produces two. Each further call adds another. Also, if a caller passes their own list, `tags.append(...)` mutates it as a side effect. Genuine bug.
3. `moving_average([1, 2, 3, 4], 2)` — `range(len(values) - window)` is `range(2)`, so `start` is 0 and 1, giving chunks `[1, 2]` and `[2, 3]` and output `[1.5, 2.5]`. But "every consecutive window-sized slice" of a 4-element list with window 2 is three slices: `[1,2]`, `[2,3]`, `[3,4]`. The last one (`3.5`) is dropped. Off-by-one. Genuine bug.

Findings:

**Bug 1 — `tag_records`: mutable default argument that is mutated on every call.**
`tags=[]` is evaluated once, so the same list persists across calls. `tags.append("processed")` grows it each time, so the second call tags records with `['processed', 'processed']`, the third with three, and so on. It also mutates any list the caller passes in. Fix: default to `None` and build a fresh list without touching the input.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags or []) + ["processed"]
    return [dict(record, tags=list(tags)) for record in records]
```

Now both calls print `[{'id': 1, 'tags': ['processed']}]` and `[{'id': 2, 'tags': ['processed']}]`.

**Bug 2 — `moving_average`: loop range is one short.**
`range(len(values) - window)` omits the final window. For `n` values and window `w` there are `n - w + 1` full slices. Fix:

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```

`moving_average([1, 2, 3, 4], 2)` now returns `[1.5, 2.5, 3.5]`.

**Not a bug — `number_lines`.** `enumerate(lines, start=1)` already produces the 1-based `'1: first'` format the docstring describes; left unchanged.
