**Bug 1 — `tag_records`: mutable default argument that gets mutated**

`tags=[]` is evaluated once at definition time, and `tags.append("processed")` mutates that shared list. Every call without an explicit `tags` piles on another `"processed"`, so the second call in `__main__` yields `tags=['processed', 'processed']`. It also silently mutates any list a caller passes in. Fix: default to `None`, and build a new list instead of appending to the argument.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags or ()) + ["processed"]
    return [dict(record, tags=list(tags)) for record in records]
```

Now both `print(tag_records(...))` calls produce `[{'id': N, 'tags': ['processed']}]`, and a caller's own list is left untouched.

**Bug 2 — `moving_average`: off-by-one in the loop bound**

`range(len(values) - window)` stops one short. With 4 values and window 2 there are 3 valid slices (`[1,2]`, `[2,3]`, `[3,4]`), but the loop runs `start = 0, 1` only, dropping the last window. The number of complete windows is `len(values) - window + 1`.

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```

`moving_average([1, 2, 3, 4], 2)` now returns `[1.5, 2.5, 3.5]` instead of `[1.5, 2.5]`.
