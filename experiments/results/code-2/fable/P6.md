**Function: `tag_records`**
Problem: `tags=[]` is a mutable default, and the function mutates it with `tags.append("processed")`. The same list is reused across calls, so each call appends another `"processed"`: the first call yields `["processed"]`, the second `["processed", "processed"]`, and so on. Passing an explicit list has the same problem — the caller's list gets modified.
Fix: default to `None` and build a fresh list inside the function instead of appending to the argument.

```python
def tag_records(records, tags=None):
    """Attach `tags` plus a 'processed' marker to every record."""
    tags = list(tags) if tags is not None else []
    tags.append("processed")
    return [dict(record, tags=list(tags)) for record in records]
```

**Function: `moving_average`**
Problem: `range(len(values) - window)` is off by one. There are `len(values) - window + 1` consecutive windows, so the last slice is never computed. For `[1, 2, 3, 4]` with window 2 it returns `[1.5, 2.5]` instead of `[1.5, 2.5, 3.5]`.
Fix: extend the range by one.

```python
def moving_average(values, window):
    """Return the average of every consecutive `window`-sized slice."""
    averages = []
    for start in range(len(values) - window + 1):
        chunk = values[start:start + window]
        averages.append(sum(chunk) / window)
    return averages
```
