All 43 cases pass (15 valid, 28 invalid). Here is the reasoning and the tested implementation.

## Reasoning

**The grammar.** A duration is `P` followed by either a date part, a time part, or both:

```
duration := "P" ( n "W" | [n"Y"] [n"M"] [n"D"] [ "T" [n"H"] [n"M"] [n"S"] ] )
```

Two things make this more than a simple "scan number+letter pairs" problem:

1. **`M` is ambiguous.** It means months before `T` and minutes after it. Position relative to the `T` separator is the only disambiguator, so the parser must be positional, not a token loop.
2. **Order is fixed.** `Y M D T H M S`, largest to smallest. `P1D2Y` is not a valid reordering — it's invalid.

Weeks are their own alternative in the standard: `PnW` does not combine with other designators.

**Strings that look valid but aren't**, and how each is caught:

| Input | Why invalid | Detection |
|---|---|---|
| `P`, `PT` | No components at all | Regex makes every group optional, so both match — an explicit "all groups are None" check rejects them |
| `P1YT` | `T` present but no time components | Explicit check: `"T" in s` and all of hours/minutes/seconds are None |
| `P1S`, `P1H` | Time unit without the `T` separator | `S`/`H` only appear inside the `T` branch of the regex |
| `PT1D` | Date unit after `T` | `D` only appears before the `T` branch |
| `P1.5D`, `PT1.5H` | Fraction outside seconds | The `[.,]\d+` group is attached only to the seconds field |
| `PT.5S` | Fraction with no integer part | `\d+` before the fraction is required (ISO demands at least one digit) |
| `P1W2D` | Weeks mixed with other units | `W` is an exclusive alternation branch |
| `P1D2Y` | Wrong order | Regex is positional |
| `p1d`, `P1D `, `P1X` | Case, whitespace, unknown chars | Anchored `^...$` with an uppercase-only alphabet |

**Design choices.** Anchoring with `^...$` means the "unknown characters" rule is enforced for free rather than by an explicit character check. The two structural cases the regex can't express (empty `P`, dangling `T`) are the only ones needing imperative checks after the match.

Whole seconds are accumulated as `int` and only the seconds field becomes a `float` when it actually carries a fraction — so `P1Y2M3DT4H5M6S` returns an exact `int` with no float rounding on large day counts, while `PT1.5S` returns `1.5`. That satisfies the `float | int` signature naturally.

I also accept `,` as a decimal separator, since ISO-8601 permits it alongside `.` — remove `,` from the seconds group if you want period-only.

Non-string input raises `ValueError` rather than `TypeError`, on the grounds that the spec asks for `ValueError` on anything that isn't a valid duration; swap it if you prefer stricter Python convention.

## Code:

```python
import re

_DURATION_RE = re.compile(
    r"""^P(?:
            (?P<weeks>\d+)W
          |
            (?:(?P<years>\d+)Y)?
            (?:(?P<months>\d+)M)?
            (?:(?P<days>\d+)D)?
            (?:T
                (?:(?P<hours>\d+)H)?
                (?:(?P<minutes>\d+)M)?
                (?:(?P<seconds>\d+(?:[.,]\d+)?)S)?
            )?
        )$""",
    re.VERBOSE,
)

_SECONDS_PER = {
    "years": 365 * 24 * 3600,
    "months": 30 * 24 * 3600,
    "weeks": 7 * 24 * 3600,
    "days": 24 * 3600,
    "hours": 3600,
    "minutes": 60,
}


def parse_iso_duration(s):
    """Convert an ISO-8601 duration string to a total number of seconds.

    Grammar accepted:  P[nY][nM][nD][T[nH][nM][nS]]  or  PnW
    A fraction ('.' or ',') is allowed only on the seconds field.
    1 year = 365 days, 1 month = 30 days, 1 week = 7 days.

    Returns an int when the duration is a whole number of seconds,
    otherwise a float.  Raises ValueError on anything else.
    """
    if not isinstance(s, str):
        raise ValueError(f"expected a string, got {type(s).__name__}")

    m = _DURATION_RE.match(s)
    if m is None:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    parts = m.groupdict()

    # The regex makes every component optional, so "P", "PT" and "P1DT" match.
    if all(v is None for v in parts.values()):
        raise ValueError(f"duration has no components: {s!r}")
    if "T" in s and all(parts[k] is None for k in ("hours", "minutes", "seconds")):
        raise ValueError(f"'T' separator with no time components: {s!r}")

    total = 0
    for name, factor in _SECONDS_PER.items():
        if parts[name] is not None:
            total += int(parts[name]) * factor

    sec = parts["seconds"]
    if sec is not None:
        sec = sec.replace(",", ".")
        total += float(sec) if "." in sec else int(sec)

    return total
```
