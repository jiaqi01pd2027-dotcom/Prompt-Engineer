```python
import re

_DURATION_RE = re.compile(
    r"""
    ^P
    (?:(?P<years>\d+)Y)?
    (?:(?P<months>\d+)M)?
    (?:(?P<weeks>\d+)W)?
    (?:(?P<days>\d+)D)?
    (?:
        (?P<t>T)
        (?:(?P<hours>\d+)H)?
        (?:(?P<minutes>\d+)M)?
        (?:(?P<seconds>\d+(?:\.\d+)?)S)?
    )?
    $
    """,
    re.VERBOSE,
)

_UNIT_SECONDS = {
    "years": 365 * 24 * 3600,
    "months": 30 * 24 * 3600,
    "weeks": 7 * 24 * 3600,
    "days": 24 * 3600,
    "hours": 3600,
    "minutes": 60,
}


def parse_iso_duration(s):
    """Return the total number of seconds in the ISO-8601 duration ``s``."""
    if not isinstance(s, str):
        raise TypeError(f"expected a string, got {type(s).__name__}")

    match = _DURATION_RE.match(s)
    if match is None:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    parts = match.groupdict()
    has_time = any(parts[n] is not None for n in ("hours", "minutes", "seconds"))
    has_date = any(parts[n] is not None for n in ("years", "months", "weeks", "days"))

    if not has_date and not has_time:
        raise ValueError(f"no components in {s!r}")
    if parts["t"] is not None and not has_time:
        raise ValueError(f"'T' with no time components in {s!r}")

    total = 0
    for name, unit_seconds in _UNIT_SECONDS.items():
        if parts[name] is not None:
            total += int(parts[name]) * unit_seconds

    seconds = parts["seconds"]
    if seconds is not None:
        total += float(seconds) if "." in seconds else int(seconds)

    return total
```

Design decisions worth flagging:

- **Return type**: `int` unless the string carries a decimal fraction on seconds, in which case `float`. `"P1DT12H"` → `129600` (int), `"PT0.25S"` → `0.25` (float). Fractional values that are exact binary fractions (0.25, 1.5) come back exact.
- **`M` disambiguation** comes free from the regex structure: before `T` it is months, after it is minutes. `"P1M"` → 2592000, `"PT1M"` → 60.
- **Error messages**: `"PT"` and `"P"` give `no components in '<s>'` per the spec; a dangling `T` with date parts only (`"P1DT"`) gives `'T' with no time components in 'P1DT'`; everything else that fails the grammar gives `invalid ISO-8601 duration: '<s>'`.
- **Weeks mixed with other components** (`"P1W1D"` → 691200) is accepted. Strict ISO-8601 treats `PnW` as its own exclusive form, but the spec's invalid list didn't mention mixing, so I went permissive. Say the word if you want `"P1W1D"` to raise instead — it's a one-line regex change (make the week branch an alternative).
- **Strict on the rest**: lowercase (`"p1d"`), comma decimals (`"PT1,5S"`), leading/trailing whitespace, signs (`"-PT1S"`, `"P-1D"`), out-of-order units (`"P1M1Y"`), repeated units, fractions on non-seconds (`"P1.5D"`, `"PT1.5H"`), and bare `.5` fractions all raise `ValueError`. Non-string input raises `TypeError`, which felt more Pythonic than forcing it into `ValueError`.
