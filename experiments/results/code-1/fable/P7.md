All 11 valid cases and 26 invalid cases pass (including `"PT1S\n"`, which a `$`-anchored regex would wrongly accept).

## Code:

```python
import re

_WEEK_RE = re.compile(r"P(\d+)W")
_FULL_RE = re.compile(
    r"P"
    r"(?:(\d+)Y)?"
    r"(?:(\d+)M)?"
    r"(?:(\d+)D)?"
    r"(?:T"
    r"(?:(\d+)H)?"
    r"(?:(\d+)M)?"
    r"(?:(\d+(?:[.,]\d+)?)S)?"
    r")?"
)

_SECONDS_PER = {
    "Y": 365 * 86400,
    "M": 30 * 86400,
    "W": 7 * 86400,
    "D": 86400,
    "H": 3600,
    "MIN": 60,
}


def parse_iso_duration(s):
    """Convert an ISO-8601 duration string to a total number of seconds.

    Uses 365 days per year and 30 days per month. Returns an int unless the
    seconds component carries a fraction, in which case a float is returned.
    Raises ValueError for anything that is not a valid ISO-8601 duration.
    """
    if not isinstance(s, str):
        raise ValueError(f"expected str, got {type(s).__name__}")

    m = _WEEK_RE.fullmatch(s)
    if m:
        return int(m.group(1)) * _SECONDS_PER["W"]

    m = _FULL_RE.fullmatch(s)
    if not m:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    years, months, days, hours, minutes, seconds = m.groups()

    # "P" alone, or a T with no time components after it.
    if all(g is None for g in m.groups()):
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")
    if "T" in s and hours is None and minutes is None and seconds is None:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    total = 0
    if years:
        total += int(years) * _SECONDS_PER["Y"]
    if months:
        total += int(months) * _SECONDS_PER["M"]
    if days:
        total += int(days) * _SECONDS_PER["D"]
    if hours:
        total += int(hours) * _SECONDS_PER["H"]
    if minutes:
        total += int(minutes) * _SECONDS_PER["MIN"]
    if seconds:
        seconds = seconds.replace(",", ".")
        if "." in seconds:
            total += float(seconds)
        else:
            total += int(seconds)

    return total
```

Notes on behavior:
- `"P1Y2M3DT4H5M6S"` → 36993906, `"P2W"` → 1209600, `"PT1.5S"` → 1.5, `"PT36H"` → 129600, `"P1DT12H"` → 129600.
- Both `.` and `,` are accepted as the decimal mark in seconds, per ISO-8601.
- Rejected: `""`, `"P"`, `"PT"`, `"P1YT"`, `"P4H"`, `"P5S"`, `"P1.5D"`, `"PT1.5H"`, `"P1W2D"`, `"P2WT1H"`, `"P1D2Y"`, `"p1d"`, leading/trailing whitespace or newline, negative values, repeated units.
- Deliberately excluded (as the spec does not ask for them): the extended `PYYYY-MM-DDThh:mm:ss` form and the non-standard negative durations some libraries accept.
