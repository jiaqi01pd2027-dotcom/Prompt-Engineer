All clarifying questions were already answered in the spec, so I went straight to implementation. Here is the function, standard library only:

```python
from __future__ import annotations

import re

_PATTERN = re.compile(
    r"P(?:"
    r"(?P<weeks>\d+)W"                      # weeks form: P<n>W, nothing else
    r"|"
    r"(?:(?P<years>\d+)Y)?"
    r"(?:(?P<months>\d+)M)?"
    r"(?:(?P<days>\d+)D)?"
    r"(?:T"
    r"(?:(?P<hours>\d+)H)?"
    r"(?:(?P<minutes>\d+)M)?"
    r"(?:(?P<seconds>\d+(?:\.\d+)?)S)?"    # only seconds may be fractional
    r")?"
    r")"
)

_SECONDS_PER = {
    "years": 365 * 86400,
    "months": 30 * 86400,
    "weeks": 7 * 86400,
    "days": 86400,
    "hours": 3600,
    "minutes": 60,
}


def parse_iso_duration(s: str) -> float | int:
    """Convert an ISO-8601 duration string (e.g. "P1DT12H") to total seconds.

    Fixed unit lengths: year = 365 days, month = 30 days, week = 7 days,
    day = 24 hours. Weeks must appear alone ("P2W"). Only the seconds
    component may be fractional. Raises ValueError for any invalid input.
    """
    if not isinstance(s, str):
        raise ValueError(f"expected str, got {type(s).__name__}")

    m = _PATTERN.fullmatch(s)  # fullmatch: no leading/trailing junk, no trailing newline
    if m is None:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    parts = {k: v for k, v in m.groupdict().items() if v is not None}
    if not parts:
        raise ValueError(f"duration has no components: {s!r}")
    if "T" in s and not any(k in parts for k in ("hours", "minutes", "seconds")):
        raise ValueError(f"time separator with no time components: {s!r}")

    total = sum(int(parts[k]) * n for k, n in _SECONDS_PER.items() if k in parts)
    sec = parts.get("seconds")
    if sec is not None:
        total += float(sec) if "." in sec else int(sec)
    return total
```

**How it maps to the spec**

- The regex has two branches: a standalone weeks form (`P2W`) or the Y/M/D[T H/M/S] form, so `P1W2D` and `P2D1W` are rejected by structure alone.
- Only the `seconds` group allows a decimal, so `P1.5D` / `PT1.5H` fail to match.
- Time units outside the `T` block (`P1S`, `P1H`) fail to match; a bare `P`, `PT`, or `P1DT` matches the regex but is caught by the two explicit checks after it.
- `fullmatch` (rather than `^...$`) also rejects a trailing newline, which `$` would silently accept.
- Return type is `int` for whole-number results and `float` only when a fractional seconds value is present (`PT1.5S` -> `1.5`).

**Verified** on Python 3.9.6: all five required inputs produce the correct values (`P1Y2M3DT4H5M6S` = 36993906, `P2W` = 1209600, `PT1.5S` = 1.5, `PT36H` = 129600, `P1DT12H` = 129600), and 25 invalid inputs (empty string, `P`, `PT`, `1D`, `P1S`, `P1W2D`, `P1.5D`, `P1DT`, `P1X`, `P-1D`, lowercase, whitespace, trailing newline, comma decimal, non-string) all raise `ValueError`.

One note: `from __future__ import annotations` is included because the `float | int` annotation in the signature is a runtime `TypeError` on Python < 3.10 (which is what this machine has); it is harmless on newer versions.
