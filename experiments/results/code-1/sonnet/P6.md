## Solution

```python
import re

_WEEK_RE = re.compile(r"P(\d+)W")

_FULL_RE = re.compile(
    r"P"
    r"(?:(\d+)Y)?"
    r"(?:(\d+)M)?"
    r"(?:(\d+)D)?"
    r"(?:T(?:(\d+)H)?(?:(\d+)M)?(?:(\d+(?:\.\d+)?)S)?)?"
)

_SECONDS_PER_YEAR = 365 * 24 * 3600
_SECONDS_PER_MONTH = 30 * 24 * 3600
_SECONDS_PER_DAY = 24 * 3600
_SECONDS_PER_HOUR = 3600
_SECONDS_PER_MINUTE = 60


def parse_iso_duration(s):
    """Convert an ISO-8601 duration string into a total number of seconds.

    Years are treated as 365 days and months as 30 days. Weeks (``P2W``) are
    supported as a standalone form. Fractional seconds are supported (e.g.
    ``PT1.5S``); no other component may be fractional. Raises ValueError for
    any string that is not a valid ISO-8601 duration.
    """
    if not isinstance(s, str):
        raise ValueError(f"not a string: {s!r}")

    week_match = _WEEK_RE.fullmatch(s)
    if week_match:
        weeks = int(week_match.group(1))
        return weeks * 7 * _SECONDS_PER_DAY

    match = _FULL_RE.fullmatch(s)
    if not match:
        raise ValueError(f"invalid ISO-8601 duration: {s!r}")

    years, months, days, hours, minutes, seconds = match.groups()

    if all(g is None for g in (years, months, days, hours, minutes, seconds)):
        raise ValueError(f"no components in {s!r}")

    total = 0
    if years is not None:
        total += int(years) * _SECONDS_PER_YEAR
    if months is not None:
        total += int(months) * _SECONDS_PER_MONTH
    if days is not None:
        total += int(days) * _SECONDS_PER_DAY
    if hours is not None:
        total += int(hours) * _SECONDS_PER_HOUR
    if minutes is not None:
        total += int(minutes) * _SECONDS_PER_MINUTE
    if seconds is not None:
        if "." in seconds:
            total += float(seconds)
        else:
            total += int(seconds)

    return total
```

### How it works

- **Weeks are standalone**: `P(\d+)W` is tried first as a full match — if a string mixes `W` with anything else (e.g. `P2WT1H`), it fails that pattern and also fails the main pattern (which has no `W`), so it correctly raises `ValueError`.
- **Main pattern** enforces strict ISO order `P[nY][nM][nD][T[nH][nM][nS]]`, with digit-only groups for everything except seconds, which allows an optional decimal (`\d+(?:\.\d+)?`). This naturally rejects: no leading `P`, empty `P`/`PT`, time units placed before `T` (e.g. `P1H`), fractions anywhere but seconds (e.g. `P1.5D`, `PT1.5M`), unknown characters, and wrong component ordering (regex backtracking can't satisfy the fixed order, so `fullmatch` fails).
- **No components check**: since every group in the main regex is optional, `P` and `PT` both match syntactically but capture nothing — `all(g is None ...)` catches that and raises `ValueError(f"no components in {s!r}")`, matching the required message for `PT`.
- **Return type**: seconds without a `.` are added as `int`, so most durations return `int` (e.g. `129600`); a fractional-second component promotes the running total to `float` (e.g. `0.25`, `1.5`), matching the examples.
