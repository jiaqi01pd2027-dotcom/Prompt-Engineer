```python
import re


def parse_iso_duration(s: str) -> float | int:
    """
    Convert an ISO-8601 duration string into a total number of seconds.

    Supports the standard "PnYnMnDTnHnMnS" form (any subset of components,
    in that order), the standalone week form "PnW", and fractional seconds
    (e.g. "PT1.5S"). Raises ValueError for anything that is not a valid
    ISO-8601 duration.

    Unit-length assumptions used for the conversion:
        1 year   = 365 days
        1 month  = 30 days
        1 week   = 7 days
        1 day    = 24 hours

    Args:
        s: An ISO-8601 duration string, e.g. "P1Y2M3DT4H5M6S", "P2W",
           "PT1.5S", "PT36H", "P1DT12H".

    Returns:
        Total duration in seconds, as an int when the result is a whole
        number and a float otherwise.

    Raises:
        ValueError: If `s` is not a syntactically valid ISO-8601 duration.
    """
    if not isinstance(s, str):
        raise ValueError(f"Invalid ISO-8601 duration: {s!r}")

    week_match = re.fullmatch(r"P(\d+)W", s)
    if week_match:
        return int(week_match.group(1)) * 7 * 24 * 3600

    pattern = re.compile(
        r"^P"
        r"(?:(?P<years>\d+)Y)?"
        r"(?:(?P<months>\d+)M)?"
        r"(?:(?P<days>\d+)D)?"
        r"(?:T"
        r"(?:(?P<hours>\d+)H)?"
        r"(?:(?P<minutes>\d+)M)?"
        r"(?:(?P<seconds>\d+(?:\.\d+)?)S)?"
        r")?$"
    )
    m = pattern.fullmatch(s)
    if not m:
        raise ValueError(f"Invalid ISO-8601 duration: {s!r}")

    parts = m.groupdict()
    if all(v is None for v in parts.values()):
        raise ValueError(f"Invalid ISO-8601 duration: {s!r}")

    if "T" in s and parts["hours"] is None and parts["minutes"] is None and parts["seconds"] is None:
        raise ValueError(f"Invalid ISO-8601 duration: {s!r}")

    years = int(parts["years"]) if parts["years"] else 0
    months = int(parts["months"]) if parts["months"] else 0
    days = int(parts["days"]) if parts["days"] else 0
    hours = int(parts["hours"]) if parts["hours"] else 0
    minutes = int(parts["minutes"]) if parts["minutes"] else 0
    seconds = float(parts["seconds"]) if parts["seconds"] else 0.0

    total = (
        years * 365 * 24 * 3600
        + months * 30 * 24 * 3600
        + days * 24 * 3600
        + hours * 3600
        + minutes * 60
        + seconds
    )

    if total.is_integer():
        return int(total)
    return total
```

Assumptions
- 1 year = 365 days, 1 month = 30 days, 1 week = 7 days, 1 day = 24 hours; no calendar or leap-year awareness.
- The week designator (`PnW`) is treated as a standalone form and cannot be combined with year/month/day/time components.
- Fractional amounts are permitted only in the seconds field, using a decimal point (not a comma).
- A bare `P`/`PT`, or a `T` separator with no `H`/`M`/`S` following it, is rejected as invalid.
- Matching is case-sensitive and exact (`re.fullmatch`); lowercase letters, extra whitespace, or unrecognized characters raise `ValueError`.
