# Prompt Engineer

A research project, a Claude Code skill, and a website about how the wording of a
prompt changes what a model produces.

- `skill/prompt-engineer/` - the `/prompt-engineer` skill: interviews you, grades your
  prompt out of 100, rewrites it three ways adapted to your project, and explains which
  patterns it applied.
- `experiments/` - 12 tasks x 10 prompt patterns x 3 Claude models, blind-judged.
- `paper/` - the write-up.
- `site/` - the website (pattern library, results, prompt grader).
- `research/` - literature and practitioner notes the paper draws on.

Author: Tiger Zhang.
